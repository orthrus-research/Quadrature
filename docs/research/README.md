Each finding carries a basis mark:

- **[V]** verified against a source read on the date given
- **[K]** established knowledge, not re-read against a primary source in this pass
- **[M]** needs a measurement or prototype; no answer yet

A [K] finding is a starting position, not a settled one. The follow-up list at the end of
each file names what must be raised to [V] or measured before the architecture depends on
it.
